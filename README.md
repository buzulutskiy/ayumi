# Разбег

Одностраничное веб-приложение: адаптивный план бега на 26 недель, загрузка тренировок файлами, статистика, награды и маршрут от Волжского до Петербурга с фактами о местах.

Весь код — в `index.html`. Ни библиотек, ни сборки, ни сети. Данные лежат в `localStorage` браузера.

## Как открыть на iPhone

Локально: `python3 -m http.server 4181` в этой папке, затем открыть `http://<ip-мака>:4181` с телефона в одной сети.
На постоянку — положить `index.html` на GitHub Pages и добавить страницу на экран «Домой» (Поделиться → На экран «Домой»). Приложение откроется без адресной строки и будет работать офлайн.

## Без настройки

Онбординга нет. При первом открытии сразу создаётся план: два дня в неделю (среда и воскресенье), 8 км на первую неделю, цель «просто бегать». Бегать в любой другой день ничто не мешает — лишняя пробежка засчитывается сверх плана.

Стартовый объём подстраивается сам: после загрузки файла берётся медиана недельных объёмов за последние восемь недель и подставляется в план (`calibrate`). Руками ничего вводить не нужно.

## Экраны

- **Сегодня** — одна цифра: сколько бежать сегодня и как. Полоска недели, шаг по маршруту, три ключевых числа.
- **План** — все 26 недель, каждую можно развернуть до конкретных тренировок.
- **Прогресс** — объём по неделям (факт против плана), динамика темпа, список пробежек.
- **Путь** — набеганные километры откладываются по дороге Волжский → Санкт-Петербург, 1640 км, 29 остановок. Три отрезка: Волга и донская степь (до Борисоглебска), Черноземьем к Москве, Государева дорога до Невы. Каждая остановка открывает факт о месте, непройденные видны, но закрыты. Ниже — 22 медали.
- **Ещё** — загрузка файлов, ручная отметка, выгрузка/загрузка JSON, настройки программы.

## Как считается план

План нигде не хранится — он каждый раз пересчитывается из профиля и реальных пробежек (`buildPlan`).

- Тренд объёма растёт на 7% в неделю, каждая 4-я неделя разгрузочная (78% от тренда), потолок зависит от цели (30 / 40 / 54 км).
- После каждой закрытой недели тренд правится по факту: выполнено на 90%+ — рост; 60–90% — стоим; меньше — минус 10%; пропущено полностью — минус 15%.
- Длинная тренировка — 33–40% недельного объёма в зависимости от числа дней, но не больше потолка цели.
- Скоростная работа (интервалы / темповая) включается с 5-й недели и только когда недельный объём дорос до 18 км.
- Режим «бег-ходьба» (включается в настройках) первые 6 недель даёт подходы по 2 минуты трусцой и 2 минуты шагом.

Пропуск тренировки ничего не ломает: неделя просто закрывается с недобором, план следующей недели сдвигается вниз, приложение об этом прямо пишет.

## Загрузка пробежек

Главная кнопка на экране «Сегодня» открывает выбор файлов — вручную километры вводить не нужно (ручная отметка осталась второй кнопкой на всякий случай).

- **TCX** — основной формат, по файлу на тренировку. Берутся `Id` (дата и время), сумма `DistanceMeters` и `TotalTimeSeconds` по всем кругам. Если дистанция в файле нулевая, она считается по координатам трекпоинтов.
- **GPX** — длина считается по точкам трека формулой гаверсинуса, время — по первой и последней метке.
- **activities.csv** из архива Strava — вся история разом; парсер понимает русские и английские заголовки.

Можно выбрать сразу несколько файлов. Велосипед, плавание и ходьба отсеиваются по названию вида активности. Дубли режутся по паре «дата + дистанция», так что один и тот же файл можно грузить повторно без последствий.

## Маршрут

`ROUTES` в `index.html` — три отрезка с остановками и фактами. Чтобы продлить путь за Петербург, достаточно дописать четвёртый объект: километры внутри отрезка считаются от его начала, абсолютные — автоматически.
